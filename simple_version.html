Model

SmolLM2 135M Instruct by Hugging Face TB — an ultra-light instruction-tuned LLM. ~110 MB on disk, runs entirely in your browser via @huggingface/transformers (ONNX Runtime Web on WebGPU or WASM).

About this app

Offline AI Chat is a single-file, fully client-side chat app. Once the model is cached, it works without an internet connection for inference — live grounding still uses Wikipedia / Britannica / BBC when online.

How it works

  • Inference: SmolLM2 135M runs locally via transformers.js, accelerated with WebGPU when available.
  • Grounding: Each question triggers a BM25 retrieval over your local KB plus optional live lookups, injected as authoritative context.
  • Storage: Chats and the knowledge base are persisted in OPFS — capable of multi-GB capacity.
  • Auto-feed: A background streamer ingests new articles to grow the KB while idle.

Privacy

Your conversations never leave the device. Only the model download and live-source HTTP requests touch the network.
