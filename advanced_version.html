About Offline AI Chat

A privacy-first, fully in-browser AI assistant. Models, knowledge base, and chat history all live on your device — nothing is ever sent to a server we control.

What it does

  • Runs open-source LLMs locally via WebGPU / WASM (Transformers.js).
  • Grounds answers with live snippets from Wikipedia, Britannica, and BBC News.
  • Stores knowledge and chats in OPFS so it works after the first download — even offline.
  • Generates images, video, and code editors directly in the chat.
  • Real-time voice mode: speaks each sentence the moment the model writes it.

Our principles

  • Private by default — all inference happens in your browser tab.
  • Open — built on open models, open standards, and a single HTML file.
  • Offline-first — once cached, no network is required.
